# 首期后端变更与 GitHub 构建

2026-11-17 用户决定：首期改为坚果云 WebDAV；OneDrive/Entra 验证暂停。本文覆盖此前文档中的首期 OneDrive 决策，历史调研保留。

## 坚果云连接

账户信息 → 安全选项 → 第三方应用管理 → 添加应用密码，名称建议 Wencrypt P0。不要使用账号登录密码，也不要在聊天、代码、命令行参数或 GitHub Secrets 中提交个人应用密码。

本机执行：

```sh
python3 tools/jianguoyun_probe.py
```

隐藏输入应用密码。工具固定访问 https://dav.jianguoyun.com/dav/，拒绝重定向，每次请求间隔至少4秒；仅创建随机命名的测试目录、上传公开测试密文并验证重复写入、下载与 PROPFIND。不会删除文件；测试目录可自行清理。账号和密码只在进程内，不保存，Python 不保证内存擦除。

坚果云应用密码不是 Graph AppFolder 权限：应用内使用专属目录只是路径约束，不能声称凭据由服务端隔离到该目录。实际授权范围以账户能力为准。密文内的敏感数据仍由本地加密保护。

## 必须修订的同步参数

官方文档：免费版600次/30分钟，付费1500次/30分钟；单次目录列举最多750项，支持分页但标准 WebDAV 不定义统一分页参数。来源：https://help.jianguoyun.com/?p=2064 。不得套用 Graph nextLink。

正式布局调整为 `Wencrypt/vaults/<vault-id>/objects/<哈希前两位>/<完整哈希>.wenc`，最多256个哈希桶，桶按需创建。普通扫描不得每次无条件遍历所有桶；后台扫描需持久游标、请求预算及退避。所有请求（含列表/重试）共用默认4秒间隔，不保证其他应用消耗额度时仍够用。

桶列举达到700项即报告容量/完整性风险，不确认同步完成；生产适配器上线前验证服务端分页或受控进一步分桶，不能仅靠“通常均匀”保证完整性。10,000修订冷启动需计入请求预算，可能耗时数小时，应实测，不能承诺瞬时同步。不可变修订、父版本冲突规则、加密格式保持不变。

WEN-002 改为坚果云应用密码认证、MKCOL/PUT/GET/PROPFIND、限流和凭据撤销验证；WEN-013改为坚果云适配器。刷新Token测试不再适用。其余任务不因后端切换自动视为完成。

## GitHub 自动构建

`.github/workflows/ci.yml` 在 push、PR 和手动触发时运行 Rust 测试、Clippy、格式检查和 Python 探针测试，再构建三端开发产物，上传 Actions artifacts，保留14天。

Windows：未签名 Release 文件夹（需完整下载解压，不只是 exe）。macOS：临时签名的 .app ZIP，未公证。Android：调试签名 ARM64 APK；不同CI运行的调试密钥可能不同，不能用于稳定升级。

这不是正式发布流水线，不自动发布 GitHub Release，不上传任何云盘凭据。正式签名需要另建受保护的 release environment、用户提供签名证书和密钥，并审核后启用。可在仓库 Actions 页面查看真实构建结果。

开源前仍需明确项目LICENSE、固定第三方Action提交SHA和依赖许可证检查。SDK、缓存、构建产物和凭据排除在版本控制外；示例向量中的密码/密钥是明确标注的公开测试数据。

## 免费版同步预算

坚果云免费账号每月上传 1 GB、下载 3 GB，WebDAV 每 30 分钟最多 600 次请求。参考 [坚果云月流量说明](https://help.jianguoyun.com/?p=2884) 和 [WebDAV 限制](https://help.jianguoyun.com/?p=2064)。

Wencrypt 默认合计预算为上传 300 MB、下载 900 MB，按十进制字节计。Windows、macOS、Android 各分一个设备额度，每台最多上传 100 MB、下载 300 MB，每 30 分钟最多 90 次请求。三台设备合计每 30 分钟最多 270 次请求。每个账号同时最多启用三个不重复的额度。账号的全局流量还包括坚果云客户端和其他应用，Wencrypt 的本地计数只能限制自己的请求。

正式同步接入前需持久化账本，将请求及最大发送和接收字节在联网前原子预留。失败、重试和限流探测也计入预算。重装、切换设备或本地时间回拨不得恢复额度。只有确认服务端新计费周期后才能重开当期账本；无法确认时沿用原账本并暂停自动传输。账本丢失时需重新核对账号剩余额度。实际流量接近上限时降低或暂停预算。

默认只在有变化时推送，前台按需拉取，保存远端发现进度并优先复用已校验密文。额度用完后暂停网络同步并保留本地修改，继续离线使用。服务端限流或报告额度不足时暂停，遵守 Retry-After。首期不上传备份和附件。Rust 账本原型已实现预算预留与半小时窗口检查，持久化、设备分配和网络接入属于 WEN-013，不得以本地单元测试代替正式传输验收。

基础 WebDAV 探针已由用户在实际账号通过，包括建目录、重复上传、下载校验和列举。证据范围见 [P0 状态](../reports/p0-status.md)。
