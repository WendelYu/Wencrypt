安装与首次打开 Wencrypt

此 macOS 版本尚未经过 Apple 公证。

  1. 把磁盘映像中的 Wencrypt 拖到 Applications（应用程序），再从「应用程序」打开。
  2. 如果 macOS 提示无法验证开发者或无法检查 App，请确认安装包来自本仓库的 GitHub Release，然后关闭提示。
  3. 前往系统设置 → 隐私与安全性，在「安全性」下点「仍要打开」，按提示确认。

提示「已损坏」或仍然无法打开

请从 GitHub Release 重新下载 Apple 芯片版 DMG，核对 SHA256SUMS.txt 后重新安装。如果校验不符、仍提示已损坏，或 macOS 提示该 App 将损坏电脑，请停止打开并在仓库提交问题，附上 macOS 版本和完整提示。
