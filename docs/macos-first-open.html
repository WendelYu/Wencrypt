安装与首次打开 Wencrypt

此 macOS 版本尚未经过 Apple 公证。

  1. 此 DMG 适用于 Apple 芯片。把磁盘映像中的 Wencrypt 拖到 Applications（应用程序），再从「应用程序」打开。
  2. 如果 macOS 提示无法验证开发者或无法检查 App，请确认安装包来自本仓库的 GitHub Release，然后关闭提示。
  3. 前往系统设置 → 隐私与安全性，在「安全性」下点「仍要打开」，按提示确认。

提示「已损坏」或仍然无法打开

请从本仓库的 GitHub Release 重新下载 Apple 芯片版 DMG，并核对 SHA256SUMS.txt。在终端输入 shasum -a 256 和一个空格，再将下载的 DMG 拖进终端，按回车即可查看摘要。

确认摘要一致、应用已拖入「应用程序」，且系统未提示恶意软件时，可在终端执行下面的命令清除该应用的下载隔离标记，然后重新打开 Wencrypt。

xattr -dr com.apple.quarantine "/Applications/wencrypt.app"

校验不符、系统提示 App 会损坏电脑，或执行后仍无法打开时，请停止尝试并在仓库提交问题，附上 macOS 版本和完整提示。
