# Wencrypt 0.1 Alpha

此版本供测试数据验证，不代表安全审计完成。三端共用 Flutter 界面和 Rust 加密核心，使用主密码解锁。

## 可用流程

1. 首次启动设置至少12字符主密码；重开后输入原主密码。
2. 新增/搜索/编辑账号，复制用户名或密码，查看历史版本，移入回收站或恢复。
3. 随机生成24位密码。CSV导入支持Chrome/Edge英文列名，预览数量后再次验证主密码，事务导入，最多500行，重复导入会产生新条目。
4. 顶栏导出加密备份，需要验证主密码。全新安装通过备份恢复，已有库不被覆盖。
5. 新设备先恢复同一份备份，再使用各自的坚果云WebDAV应用密码手动同步。首次同步明确创建云端副本。
6. 同一账号的并发版本会分别显示警告图标。打开任一版本，选择基础版本、编辑并保存，会把当前所有版本作为父版本；历史仍保留。

## 免费坚果云预算

每次安装每月最多预留100MiB上传和300MiB下载，每30分钟80次请求。请求前将预算落盘，失败不退回；下载按最大响应大小预留，因此显示预算会比实际流量更保守。三台安装总预算300/900MiB，给免费账户留下余量，但不能统计其他软件、网页和重新安装产生的流量。请不要通过清理应用数据重置预算。

初版仅手动同步，不后台轮询；凭据仅本次使用，不写磁盘。固定HTTPS坚果云官方WebDAV地址，不跟随重定向。远端目录达到598个修订对象会停止上传，保护750条目录枚举限制；每次保存和删除都会新增修订。正常同步不删除远端文件。曾绑定的远端副本消失时停止同步，不自动重建。

## 格式与数据保护

WENC v1信封使用现有Argon2id + AES-256-GCM。条目修订负载为CBOR Alpha schema 1；本次不宣称已冻结正式schema。SQLite仅存bootstrap和密文对象，WAL也只写密文。DEK保留在Rust会话中，锁定释放，未经过Dart。展示条目和输入密码会经过Dart受管内存，无法承诺所有副本即时擦除。

备份为JSON容器，format=`WENBACK1-alpha`，包含bootstrap和WENC Backup类型的整体AEAD，后者认证全部修订集合。它不是正式WENBACK1发布协议。Alpha恢复文件上限2MiB；大库完整备份格式和流式接口待实现。恢复先验证完整内容，再安装新库，不覆盖已有文件。

后台/失焦和5分钟闲置锁定；复制后20秒仅在剪贴板未变化时清除。Android启用FLAG_SECURE和敏感剪贴板标记，关闭系统自动备份。操作系统剪贴板历史及第三方剪贴板工具不受本应用控制。

## 尚未完成的验收

- Mac/Android生物识别目前仅在设备诊断验证，真实DEK快速解锁未接入。Windows Hello强绑定未通过；三端均使用主密码。
- 自动同步、系统安全凭据保管、快捷键、磁贴、Autofill、自定义字段编辑、词组生成器、明文CSV导出、主密码迁移延期。
- 完整Flutter包的锁屏/睡眠/取消矩阵和三台设备离线冲突/恢复演练需要实机。已通过的原生Touch ID测试不能替代应用包验收。
- 尚未独立安全审计、模糊测试和磁盘满/杀进程故障全矩阵；不能使用真实高价值密码。
- macOS暂为临时签名开发包，没有公证；Android为开发签名APK，Windows为可解压应用包。
