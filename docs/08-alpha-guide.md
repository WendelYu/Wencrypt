# Wencrypt 使用与升级说明

此版本供测试数据验证，不代表安全审计完成。三端共用 Flutter 界面和 Rust 加密核心，使用主密码解锁。

## 首次打开与现有库升级

- **第一台设备**选择「创建新库」，输入两次独立的主密码。当前版本要求至少 12 个字符。请另外妥善保存主密码和加密备份。
- **已有 Wencrypt 密码库的设备**升级后照常解锁。先升级所有参与同步的设备，再在资料最完整的原设备打开「坚果云设置」，确认主同步目录并同步到本轮完成。
- **其他设备首次打开**选择「加入已有库 → 从坚果云加入」。填写同一个坚果云账号及同步目录名、该设备的 WebDAV 应用密码，以及原库的主密码。主密码用于本机验证和解密。保留前台解锁，直到首次同步完成。也可以选择「从加密备份恢复」，再配置同一个目录。
- **已有本地库的其他设备**沿用原库并同步。若此前各自新建过库，请先保留这些库的加密备份，再处理不同库的数据迁移。首次引导仅在本机没有库时显示，同步会核对库身份。

## 可用流程

1. 在首台设备创建密码库，输入两次主密码。当前版本要求至少 12 个字符。请使用独立的长口令，并在设备之外妥善保存。
2. 新增、搜索和编辑账号，复用自定义分组，复制用户名或密码，查看历史版本。账号支持快速移入回收站。回收站支持恢复以及单条或多选清除。清除状态会同步到新版客户端，现有加密历史和备份仍会保留。
3. 随机生成 24 位密码。桌面端选择已安装的 Chrome、Edge 或 Firefox 后，会先监听导出目录，再尝试打开密码管理界面。macOS 首次打开 Chrome 或 Edge 的设置页时可能要求授权。浏览器若未进入设置页，可复制界面中的地址。导出 CSV 后确认要导入的记录和分组。网址、用户名和密码相同的记录会合并，已有标题和置顶状态保留，补充备注及分组。密码不同的记录各自保留。一次最多 500 条。
4. 从顶栏菜单导出加密备份。主密码或本机已启用的指纹都可授权导出。备份适用于重装、换机和离线恢复，恢复时需要导出时使用的库主密码。
5. 每台设备可以单独生成坚果云 WebDAV 应用密码，共用同一个主同步目录。分别创建的密码库具有不同的身份，即使主密码相同也不能互相同步。
6. 单条账号的「更多操作」提供 PNG 导出。macOS 和 Windows 复制图片到剪贴板，Android 保存到系统相册的 Wencrypt 相册。默认只包含名称、用户名和网址，可主动勾选包含密码。图片里的内容可以直接读取。
7. 同一账号的并发版本会分别显示警告图标。打开任一版本，选择基础版本、编辑并保存，会把当前所有版本作为父版本；历史仍保留。

手动选择「添加监听目录 → 记住目录」后，同一设备下次打开浏览器导入会恢复该目录。macOS 使用系统目录书签恢复访问权限。可点击目录标签上的移除按钮让应用忘记该目录。

桌面端通过侧栏切换密码库、分组、回收站和同步记录。`⌘K` 或 `Ctrl+K` 打开命令面板，可通过方向键和回车执行操作。`⌘F` 或 `Ctrl+F` 聚焦密码库搜索。

## 邀请另一台设备

1. 在已绑定同步目录的设备上，先完成同步，再从菜单选择「复制加入邀请链接」。
2. 将链接发到新设备。macOS 和 Android 可以尝试直接打开链接。所有平台都可在首次引导的「加入已有库 → 从坚果云加入」中选择「粘贴邀请链接」。
3. 确认目录，填写坚果云账号、该设备的 WebDAV 应用密码和库主密码。链接只携带目录与库标识，应用会在安装本地库前核对身份。

## 修改主密码

1. 将参与同步的设备升级到 0.3.3 或更新版本。在常用设备的菜单中选择「修改主密码」，输入当前主密码并确认新主密码。
2. 已配置同步时，应用会尝试更新云端。WebDAV 必须提供可用于条件写入的强 ETag 才能安全更新。若界面提示云端未更新，请查看同步记录中的原因。
3. 云端更新成功后，其他设备先用本机原主密码解锁，再选择「采用云端主密码」，输入新主密码。重新启用指纹解锁时使用新主密码。此前导出的加密备份仍使用导出时的主密码。

## 同步记录

「同步记录」按目录显示每轮同步的开始时间、上传和下载修订数、结果及失败原因，可筛选状态并复制目录名。上传和下载统计的是修订数，一个账号有多个历史版本时可占多条。每台设备在本地库加密保存自己的记录。

## 免费坚果云预算

每次安装每月最多预留100MiB上传和300MiB下载，每30分钟80次请求。请求前将预算落盘，中断时保留预扣额；完整响应按接收量和协议余量结算。三台安装总预算300/900MiB，给免费账户留下余量，但不能统计其他软件、网页和重新安装产生的流量。请不要通过清理应用数据重置预算。

首次录入后选择「保存并同步」，WebDAV 凭据会加密保存在本机。再次同步自动使用本机凭据，按需点「更换」即可更新账号或应用密码。凭据随本机设置保存，新设备需要分别配置。在「坚果云设置」勾选「自动同步」，应用在前台解锁时运行，正常间隔 15 分钟，失败时退避。锁定或切后台会停止当轮请求。同步分批提交，达到流量或请求额度后会在后续轮次继续。已接收且校验过的密文包会记录在本机，重启后可以继续。

旧版 598 条总修订限制已移除。新版本保留原目录下的旧密文和历史，新同步数据写入分桶的密文包。请在同一库的所有设备上使用 0.3.0 或更新版本。本机目前仍有 10,000 个修订、64 MiB 密文的存储边界。旧远端目录消失时同步暂停。把账号移入回收站会同步删除状态并保留历史。

## 格式与数据保护

WENC v1信封使用现有Argon2id + AES-256-GCM。条目修订负载为CBOR Alpha schema 1；本次不宣称已冻结正式schema。SQLite仅存bootstrap和密文对象，WAL也只写密文。DEK保留在Rust会话中，锁定释放，未经过Dart。展示条目和输入密码会经过Dart受管内存，无法承诺所有副本即时擦除。

备份为JSON容器，format=`WENBACK1-alpha`，包含bootstrap和WENC Backup类型的整体AEAD，后者认证全部修订集合。它不是正式WENBACK1发布协议。Alpha恢复文件上限2MiB；大库完整备份格式和流式接口待实现。恢复先验证完整内容，再安装新库，不覆盖已有文件。

后台/失焦和5分钟闲置锁定；复制后20秒仅在剪贴板未变化时清除。Android启用FLAG_SECURE和敏感剪贴板标记，关闭系统自动备份。操作系统剪贴板历史及第三方剪贴板工具不受本应用控制。

## 尚未完成的验收

- Mac 和 Android 在主密码解锁后的菜单中选择「启用指纹解锁」，重新验证主密码并按指纹。锁定后从「使用指纹解锁」进入。换设备或生物识别失效时用主密码重新绑定。Windows 使用主密码。
- 磁贴、Autofill、自定义字段编辑、词组生成器、明文 CSV 导出延期。
- 完整Flutter包的锁屏/睡眠/取消矩阵和三台设备离线冲突/恢复演练需要实机。已通过的原生Touch ID测试不能替代应用包验收。
- 尚未独立安全审计、模糊测试和磁盘满/杀进程故障全矩阵；不能使用真实高价值密码。
- macOS 为临时签名开发包，尚未经过 Apple 公证。请查看 DMG 内的「首次打开帮助.html」或 [Apple 官方说明](https://support.apple.com/zh-cn/102445)。Android 为开发签名 APK，Windows 为可解压应用包。

同步失败时请记录界面上的阶段、原因和 HTTP 状态。例如 authenticate / HTTP 401 通常表示账号或 WebDAV 应用密码未通过验证。复测时可以先关闭自动同步，使用一个测试条目进行手动同步。
