# Wencrypt 产品需求 v0.1

> 2026-11-17 更新：首期后端已改为坚果云 WebDAV。此前 OneDrive 首期说明由 [后端变更与构建说明](07-jianguoyun-and-github.md) 覆盖；OneDrive 验证暂停。
日期：2026-11-17。适用：个人、单用户、多个可信设备。本文定义拟实现行为，不代表已有能力。

## 1. 产品目标和安全边界

用户无需 Wencrypt 服务端账号；创建库无需联网；主密码只用于本地解密。Microsoft 登录仅授权存储访问，不用于解密密码库。掌握网盘账号者仍不应获得库内明文。

保护对象包括密码、标题、用户名、网址、备注、标签、自定义字段、历史、条目时间和删除记录。云端只保存密文对象和必要公开格式信息；文件大小、数量、访问时间和库标识仍可被存储方观察，不承诺隐藏流量特征。

不承诺防御已完全控制解锁设备的恶意软件、内核级读取、外部摄像头，也不承诺云端永不删除或拒绝提供数据。同步不能替代独立备份。没有主密码、可用解锁设备或有效恢复凭据时，厂商无法重置密码并恢复明文。

## 2. 平台及范围

- Windows 11 x64；Windows 10 的兼容性另行评估，不作为首期发布承诺。
- macOS 13+，Apple Silicon；Intel 构建作为 P0 兼容性检查后的可选目标。
- Android 10+ ARM64；模拟器另提供 x86_64 开发构建。安全功能以硬件与系统能力检测为准。
- 支持一人三端使用，每次仅一个活动库和一个同步后端。不同 Microsoft 账号间迁移使用备份导入，不直接混合远端目录。
- 不开发 Web 端，不提供团队共享、附件、Passkey、浏览器扩展或多用户权限。

最低系统版本是产品选择；构建前须按所锁定 Flutter 与插件版本复核支持矩阵。

## 3. MVP 功能

### 3.1 密码库

- 创建、打开、锁定、主密码解锁；无网络也能完整新增、查看、修改和删除。
- 条目字段：UUID、标题、用户名、密码、网址列表、备注、标签、文本自定义字段。分类以标签实现，树形目录后置。
- 自定义字段使用稳定字段 ID，支持“敏感/普通”显示属性；全部字段落盘均加密。
- 搜索标题、用户名、网址和标签；默认不搜索密码；索引只在解锁内存中建立。
- 密码与备注支持 Unicode；密码不修剪空白、不自动做 Unicode 归一化。
- 保存历史，支持查看和“恢复成一个新版本”；历史不能靠修改旧对象覆盖。
- 删除进入逻辑回收站；恢复创建新的修订。MVP 不提供历史/墓碑远端永久清理。

### 3.2 生成与复制

- 密码生成器长度 8～128，默认 24；大小写、数字、符号、排除易混淆字符可配置；至少选择一个字符集合。
- 使用系统密码学随机源和无偏采样；若要求每类字符至少一个，使用满足约束的无偏生成策略，不以固定位置拼接。
- 词组生成器默认 6 个词；使用打包、审核许可证的固定词表和无偏随机选词，展示词表大小与随机词数。不能以自然语言模型生成词组。
- 剪贴板默认 20 秒，允许 15/20/30 秒。仅在仍为本应用写入的同一剪贴板版本时清除；后续用户复制不得被覆盖。
- Android 设置敏感剪贴板标记；桌面尽可能禁止云剪贴板/历史收录，并说明第三方剪贴板工具可能仍保存副本。
- 系统挂起或进程被终止时不保证定时器准时执行，不能把清理倒计时宣传成绝对保密保证。

### 3.3 锁定及快速解锁

- 三端默认闲置 5 分钟锁定，可配置 1/5/15 分钟；系统锁屏、休眠时锁定，唤醒不自动解锁。
- Android 进入后台立即遮挡并锁定；设置 FLAG_SECURE，最近任务不得出现敏感内容。通知只显示同步状态。
- 锁定销毁 Rust 会话密钥、明文索引和缓存，清除界面数据；正在运行的异步结果不得在锁定后重新展示。
- 快速解锁需先用主密码完整解锁并由用户启用；设备密钥不进入云端或导出包。
- Android：强生物识别与 Keystore 密钥使用绑定；硬件支持状态必须检测。弱人脸不能作为强生物识别替代。
- macOS：Keychain 访问控制绑定 Touch ID；无所需能力则主密码解锁。
- Windows：Windows Hello 的 UI 验证与 DPAPI 是两个层次。仅“Hello 成功后调用 DPAPI”不能满足硬件授权绑定的底线。严格模式下，仅在 P0 证明硬件密钥使用绑定方案后开放持久快速解锁；否则该功能延期，保留主密码。不得静默改成软件保护并宣称硬件保护。
- 生物识别变更、系统密钥失效、重装或迁移后回退主密码，不能把平台异常解释成密码库损坏。

这将“所有设备都保证生物识别”修订为“支持的设备安全启用，否则主密码回退”。Windows 强绑定方案是显式发布风险，不是已解决能力。

### 3.4 同步

- 首期只支持个人 OneDrive Graph AppFolder；桌面也不依赖 OneDrive 同步客户端。
- 修改先可靠保存到本地，随后入上传队列；网络失败不撤销本地成功。
- 区分“本地已保存”“待上传”“已上传，等待检查远端”“本轮检查完成”“待解锁处理”“冲突待处理”“认证失效”。不能声称已同步到所有离线设备。
- 启动、解锁、回到前台、联网恢复及保存后触发；保存防抖合并触发，不合并掉修订；后台任务尽力调度，Android 不承诺实时后台同步。
- 锁定时可上传已生成密文、下载密文到隔离缓存，不能解密合并；OAuth 凭据可在系统安全存储中独立使用。
- 同一条目并发修改保留双方并提示选择；不同条目自动汇集。时间戳仅展示，详细规则见同步协议。

### 3.5 导入、备份与恢复

- Chrome/Edge CSV：本地读取、列映射预览、错误行提示、用户确认后导入；不上传源 CSV。不默认删除源文件。
- CSV 重试不能产生重复导入；使用本地导入批次标识。空字段、引号、换行、Unicode、超长字段需测试。
- 明文 CSV 导出要求重新验证主密码，明确提示文件含明文；文件与剪贴板均不是默认备份渠道。
- 加密备份为自包含 .wencrypt 文件；包含解锁材料和完整历史/墓碑，不包含 OAuth Token、设备解锁密钥。
- 手动导出备份要求重新输入主密码并试解密，避免只靠指纹却误以为自己知道备份密码。自动本地备份使用当前解锁会话，并在首次设置时要求验证主密码。
- 每日首次修改前在本地生成加密备份，保留最近 7 份；支持手动导出到独立存储。只保存在同一磁盘或同一网盘不构成独立灾备。
- 导入备份先打开为独立恢复库、校验并展示，再由用户决定切换或合并；绝不直接覆盖活动库。
- MVP 不发放独立恢复码，不提供“忘记主密码重置”。批量导出和主密码迁移要求知道原主密码；不能将尚可用的指纹解锁当作已验证的灾难恢复方式。
- 主密码变更采用“迁移到新库、新 DEK”的显式流程；先处理待同步修改、验证备份，再重新关联其他设备。旧离线设备修改必须另行导入。原地快速重包裹延期，避免旧云端密钥槽与并发变更含糊不清。

## 4. 原始需求延期项

- WebDAV、OneDrive 本地目录同步、企业/学校 Microsoft 账号。
- 桌面独立全局搜索浮窗；MVP 可提供快捷键唤起主窗口并定位搜索。
- Android 快捷磁贴、AutofillService；MVP 点击复制。
- 自动字段级合并、历史压缩与垃圾回收、远程设备撤销、独立恢复码。
- Windows 强硬件绑定若未通过 P0，只交付主密码的内部 Alpha，不能宣称完整满足原始生物识别底线。

## 5. 验收目标

- 1,000 条账号、10,000 次修订作为 MVP 性能测试集；超限不丢数据，显示容量提示。
- 已解锁搜索 p95 ≤100ms，本地保存 p95 ≤500ms；基于指定测试设备测量，不含网络。
- Argon2 解锁目标约 0.5～2 秒，低端机可更慢；以实测调优，不为追求速度静默降低安全参数。
- 断网、时钟偏差、乱序、重复传输、杀进程、磁盘满、损坏对象均不静默丢失已确认保存的数据。
- 发布前实际完成三端互通、全新设备恢复和主密码迁移演练；独立安全评审完成前仅使用测试/低风险数据。
