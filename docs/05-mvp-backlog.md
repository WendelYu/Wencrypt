# MVP 开发任务与验收

> 2026-11-17 更新：首期后端已改为坚果云 WebDAV。此前 OneDrive 首期说明由 [后端变更与构建说明](07-jianguoyun-and-github.md) 覆盖；OneDrive 验证暂停。
状态：P0已完成部分实机验证；Alpha已实现离线账号、事务存储、加密备份及手动同步。逐项安全验收尚未全部通过，以 reports/p0-status.md 与 docs/08-alpha-guide.md 为准。

## 1. 里程碑与依赖

顺序：P0 技术验证 → P1 安全核心 → P2 离线应用 → P3 同步 → P4 系统集成 → P5 发布验证。

P4 原型在 P0 提前做，正式集成在 P2 之后；P3 协议测试可在 P1 后先于 UI 完成。每个任务应独立提交，禁止一次 PR 混入加密、UI 和同步三个大模块。

粗估按熟悉 Flutter/Rust/原生开发的一名工程师：P0 5～8 人日、P1 8～12、P2 8～12、P3 8～12、P4 10～15、P5 8～12，合计 47～71 人日。它是排期估算，不是承诺；不包含独立审计等待、签名账号办理、商店审核及 Windows 强绑定失败后的额外研发。

内部 Alpha 可在 P3 后测试主密码解锁和同步。满足原始安全底线的 MVP 必须通过 P4 对应能力验证；不将 Alpha 包装为已完成全部三端生物识别的成品。

## 2. P0：先证明难点

### WEN-001：三端脚手架与构建基线

依赖：无。产物：Flutter + Rust workspace、FFI 示例、依赖锁定与三端构建命令。

验收：Windows x64、macOS ARM64、Android ARM64 均能安装，调用同一 Rust 函数；确认最低系统版本和 Intel Mac 可选支持范围；排除调试日志泄漏。

### WEN-002：OneDrive 最小权限与网络验证

依赖：无，可与 001 分开实施。产物：public-client 应用注册配置说明、登录/刷新原型、AppFolder 读写验证记录。

验收：仅 AppFolder 文件权限完成目录创建、列举分页、上传、下载、超时重试和注销；使用实际个人账号在目标桌面/移动网络测试。失败不得加全盘权限。记录官方权限表差异及实际响应，不把文档推测当结果。

门槛：若不可达或权限能力不成立，更新架构决策，将首期替换为明确的一个 WebDAV 服务；不得未经评估同时扩大首期范围。真实账号登录由用户完成，凭据不进入脚本/日志。

### WEN-003：设备解锁安全原型

依赖：001。产物：三端能力探测与 key-wrap/unwrap 小程序、威胁模型、API 选择记录。

验收：Android 强认证 CryptoObject 与实际密钥使用绑定；macOS Keychain 生物识别访问控制；Windows 证明每次解包裹是否硬件/认证绑定，验证取消、系统锁屏、生物信息变更、重启和密钥失效。单纯 UI 成功 + DPAPI 不算通过强绑定。

门槛：未通过的平台关闭快速解锁；Windows 若未通过，Alpha 可继续，完整安全 MVP 的该项不得标完成。需要调整底线时由用户明确决定，不能由实现悄悄降级。

### WEN-004：冻结可测试协议草案

依赖：001、002 的传输约束。产物：二进制布局测试向量、CBOR schema、DAG 模型用例、Argon2 Android 基准。

验收：人工复核长度/端序/AAD、默认 KDF 资源、容量上限；建立密码含中文/空白/组合字符的跨端向量。评审 HKDF 域分离和恢复流程。版本冻结前修正文档，不先生成真实密码库。

## 3. P1：核心与持久化

### WEN-005：加密封装和解析器

依赖：004。产物：bootstrap、revision、备份负载的 encode/decode，密钥安全缓冲区。

验收：已知向量、错误密码、头部/Tag 篡改、截断、尾随数据、资源上限、随机源失败测试；解析 fuzz 无崩溃/无失控分配；不使用自写 AES/Argon2。

### WEN-006：版本图和冲突引擎

依赖：004。产物：create/update/delete/restore/resolve、head 计算、pending 与隔离规则。

验收：同步协议全部因果/并发用例；性质测试证明集合到达顺序、重复输入不改变最终状态；父图循环、跨条目父引用、重复 revision_id 不同明文被拒绝。

### WEN-007：密文存储和 outbox

依赖：005、006。产物：SQLite schema、事务、迁移框架、隔离缓存、单写者协调。

验收：提交前/后杀进程、磁盘满、WAL 恢复、重复重试；已确认保存不丢失。扫描 DB/WAL/临时文件无测试明文标记。schema 升级失败保留原库并可恢复。

### WEN-008：备份、导入与密码迁移核心

依赖：005、006、007。产物：WENBACK1 生成/校验/独立恢复库、新 DEK 迁移。

验收：一台设备备份、另一台全新安装恢复全部条目/历史/墓碑/冲突；错误主密码不覆盖库；备份缺项/篡改检测；超过容量拒绝。迁移中断保留可打开旧库，完成后其他设备需重新绑定；旧云副本风险有明确提示。

## 4. P2：离线可用应用

### WEN-009：创建/解锁/锁定流程

依赖：005、007。产物：新库引导、主密码输入、锁定页、会话代次控制。

验收：完全断网可创建和重启解锁；主密码未发往网络；锁定中在途回调不能再次展示数据；错误密码不改变库。

### WEN-010：账号 CRUD、搜索与历史

依赖：006、009。产物：列表、详情、编辑器、标签、自定义字段、历史和回收站。

验收：全部离线使用；编辑基于实际父版本；新修订出现时不静默覆盖编辑器内容；搜索索引不落盘；1,000 条测试集完成性能测量。

### WEN-011：生成器和复制

依赖：009。产物：密码/词组生成器，三端复制接口与清理状态。

验收：字符约束、空集合、长度边界、词表许可证、无偏采样算法复核；复制后替换剪贴板不会被旧定时器误清；敏感预览标记在 Android 实机验证。

### WEN-012：CSV 与备份交互

依赖：008、010。产物：CSV 映射预览、错误行提示、加密备份、明文导出、恢复向导。

验收：Chrome/Edge 样例、含换行引号及 Unicode、取消与重复导入；明文导出重新验证主密码，源文件不上传；恢复前预览不覆盖活动库。

## 5. P3：OneDrive 同步

### WEN-013：Graph 适配器与 Token 生命周期

依赖：002、007。产物：统一存储接口、AppFolder 后端、系统安全凭据缓存。

验收：分页、刷新失败、401/403/429/503、限流、配额、超时不确定结果；跨域下载不泄漏 Bearer Token；日志不包含 Token/预授权 URL。正常同步无删除操作。

### WEN-014：同步状态机与调度

依赖：006、007、013。产物：拉取/验证/上传/复查、重试、锁定隔离、前台与网络事件触发。

验收：乱序、重复、双设备同时上传、崩溃重启收敛；锁定只传输密文；本地保存不等待网盘。完整页扫描和周期复查不会漏掉后来可见对象。

### WEN-015：冲突解决界面

依赖：010、014。产物：版本并排比较、手工字段选择、确认删除、解决结果新修订。

验收：密码默认遮挡；delete/edit 不自动复活；解决期间出现新 head 要求重新确认；另一设备并发解决后仍保留冲突；不以设备时间判断赢家。

### WEN-016：同步异常与恢复交互

依赖：008、014。产物：待同步/待解锁/数据不完整/认证失败/远端缺失等准确状态和恢复入口。

验收：目录删除不自动重建空库；密文损坏隔离且本地可用；重连不会吞掉离线修改；不宣称所有设备已同步。

P3 退出门槛：三端至少各一次离线编辑与跨设备恢复演练。此时可发布仅供测试数据的内部 Alpha。

## 6. P4：平台安全与体验

### WEN-017：快速解锁正式集成

依赖：003、009。产物：通过原型验证的平台设备包裹、能力等级、取消/失效恢复流程。

验收：DEK 不进入 Dart、不随备份/系统迁移上传，换库后旧包裹不可复用；无法通过严格策略的平台明确不开放该功能。Windows 未解决项不得用功能开关掩盖后计入完成率。

### WEN-018：系统锁定、防窥、生命周期

依赖：009、011。产物：三端闲置/锁屏/睡眠处理、Android 后台遮挡与 FLAG_SECURE、剪贴板防泄漏。

验收：系统事件在真实设备执行；Android 最近任务/截图/录屏保护；后台回调、解锁取消、系统挂起无敏感界面残留。剪贴板清理标注系统限制。

### WEN-019：桌面快捷键与 Android 调度

依赖：010、014、018。产物：桌面快捷键唤起并聚焦搜索；Android WorkManager 密文传输。

验收：锁定时只能到解锁页；快捷键冲突可配置；Android 后台受限时前台补同步，不承诺准时后台运行。独立搜索浮窗、磁贴与 Autofill 不在此任务范围。

## 7. P5：发布门槛

### WEN-020：三端端到端与故障矩阵

依赖：008～019 的相应功能。产物：可重复测试数据、故障脚本、设备/OS/版本记录与性能报告。

验收：10,000 修订规模、网络抖动、限流、进程终止、磁盘满、时间偏差、父版本缺失、离线旧设备归来、两设备同时解决、全新设备恢复与主密码迁移均通过；测试报告记录真实结果，不能只列用例即算完成。

### WEN-021：安全评审与依赖检查

依赖：005～020。产物：独立安全审查结果、修复记录、依赖/许可证清单、Token/日志/磁盘泄漏检查。

验收：高风险问题关闭；加密、解析、FFI 生命周期、认证绑定、同步和恢复纳入评审。现有算法库的审计不等于 Wencrypt 已审计。

### WEN-022：安装包、更新与操作文档

依赖：020、021。产物：三端签名安装包、安装/备份/恢复/迁移说明、已知限制和版本兼容规则。

验收：全新安装、升级、失败回退、签名密钥备份；安装器不删除用户库；文档明确保存主密码和独立备份。未通过某平台硬件能力验证时只能标注受限版本，不宣称完整安全 MVP。

## 8. 后续版本

- WebDAV：先指定坚果云或自建服务之一，复用存储接口和故障矩阵，通过后逐步增加兼容列表。
- Android Autofill：域名/包名身份校验、用户确认和锁定策略先于便利性；不按模糊标题自动填充。
- 桌面独立搜索浮窗、Android 快捷磁贴。
- 基于共同祖先的字段级自动合并；没有唯一可靠基线时仍保留冲突。
- 历史压缩与墓碑回收：先设计设备退役/确认协议，不能按固定天数直接删。
- 恢复码、设备撤销、原地主密码变更另写协议版本，不能用临时补丁改变 v1 信任模型。

## 9. 开工顺序

第一批实施 WEN-001～004；先证明三端构建、AppFolder 权限、设备解锁边界与格式测试向量。通过后实施 WEN-005～008，再进入账号界面。UI 完成不作为加密与同步安全已经成立的证据。
